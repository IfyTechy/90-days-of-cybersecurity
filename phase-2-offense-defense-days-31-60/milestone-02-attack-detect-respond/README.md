# Milestone 2 — Attack + Detect + Respond Case Study (Day 60)

> **Status:** 🔲 Pending · Due at the close of Phase 2.

One end-to-end narrative: execute an attack in the lab, show the telemetry it generated, build a detection that fires on it, and run a structured response.

## Case Study Structure

1. **Scenario & Objectives** — the attack story and the expected blue-team outcome
2. **Attack Execution** — steps with MITRE ATT&CK mapping
3. **Telemetry** — logs/events the attack produced and where they surfaced
4. **Detection Engineering** — rules or alerts built to catch it, and validation
5. **Incident Response** — containment, eradication, recovery, lessons learned
